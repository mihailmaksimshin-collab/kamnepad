# Камнепад

Статичная Telegram Mini App: камни падают на красную черту, их нужно разбивать касанием.

Страница собирается без сборки. GitHub Pages отдаёт файлы из корня ветки `main`.

https://mihailmaksimshin-collab.github.io/kamnepad/

## Версия

Единственная версия сборки — константа `VERSION` в `game.js`:

`20261120a`

При любом изменении игры поднимите эту строку и тот же токен `?v=` у всех файлов: `style.css`, `main.js` и импорт `./game.js` внутри `main.js`. Метка на стартовом экране берётся из `VERSION`.

## Как играть

- Счёт, волна и рекорд — сверху. Рекорд хранится в браузере.
- Касание или свайп бьёт по площади вокруг пальца. Можно несколькими пальцами сразу.
- За клетку +2, за полностью разбитый камень +5.
- Каждая следующая волна быстрее, крупнее и прочнее. Если клетка коснётся красной черты — камни прорвались.
